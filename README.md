EasyLearn
Online Learning Platform

EasyLearn is a web-based learning platform designed to connect learners with structured online courses and learning resources.

✨ Features
📚 Course Management — Create and organize online courses.
🎓 Learning Experience — Access course content through a structured interface.
👤 User Management — Manage learner accounts and profiles.
📈 Learning Progress — Track progress through enrolled courses.
🧑‍🏫 Course Administration — Manage courses and their learning content.
📸 Screenshots

🛠️ Tech Stack

Frontend: React · JavaScript · Tailwind CSS
Backend: Node.js · Express.js
Database: MongoDB

⚙️ Getting Started
git clone <repository-url>
cd EasyLearn
yarn install
yarn dev
🚧 Status

EasyLearn is an actively developed project focused on building a simple and scalable online learning experience.
